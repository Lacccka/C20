# Установка и настройка C++20 в Visual Studio Code

## 1. Открываем командную строку (CMD)

1. Нажмите сочетание клавиш **Win + R**.
2. В появившемся окне введите `cmd`.
3. Нажмите **ОК** или **Enter**.

## 2. Проверяем наличие пакетного менеджера WinGet

В открывшейся командной строке выполните:

```cmd
winget --version
```

Если WinGet установлен, появится информация о его версии.

> **ВАЖНО!**
>
> Если версия не выводится или появляется ошибка, напишите мне или обратитесь за помощью к любой GPT.

## 3. Устанавливаем MSYS2

В командной строке выполните:

```cmd
winget install --id MSYS2.MSYS2 -e --source winget
```

После установки MSYS2 обычно находится по пути:

```text
C:\msys64
```

> **ВАЖНО!**
>
> Проверьте вручную, где установлен MSYS2. Если путь отличается, используйте свой путь во всех последующих командах.

## 4. Обновляем MSYS2

Ранее вы проверили, где находится MSYS2. Теперь используем этот путь для обновления.

В командной строке выполните:

```cmd
C:\msys64\usr\bin\bash.exe -lc "pacman -Syu --noconfirm"
```

**Команду необходимо выполнить два раза подряд.**

Если в процессе первого обновления MSYS2 попросит закрыть терминал, выполните это требование, после чего откройте CMD заново и повторите команду.

## 5. Устанавливаем GCC и G++

В командной строке выполните:

```cmd
C:\msys64\usr\bin\bash.exe -lc "pacman -S --noconfirm mingw-w64-ucrt-x86_64-gcc"
```

> **ВАЖНО!**
>
> Если вы изменяли путь к MSYS2 в предыдущих командах, здесь его тоже необходимо изменить.

После установки компилятор G++ обычно находится по пути:

```text
C:\msys64\ucrt64\bin\g++.exe
```

> **ВАЖНО!**
>
> Проверьте вручную, существует ли файл `g++.exe` по указанному пути.

## 6. Проверяем работу G++

Используем полный путь к установленному компилятору:

```cmd
C:\msys64\ucrt64\bin\g++.exe --version
```

Если всё прошло успешно, появится информация о версии GCC.

## 7. Добавляем компилятор в PATH

Чтобы компилятор можно было запускать из любой папки, необходимо добавить путь к нему в переменную окружения `Path`.

**Способ 1. Через PowerShell**

Откройте PowerShell и выполните:

```powershell
[Environment]::SetEnvironmentVariable(
    "Path",
    [Environment]::GetEnvironmentVariable("Path", "User") + ";C:\msys64\ucrt64\bin",
    "User"
)
```

**Способ 2. Через CMD**

Если вы используете обычную командную строку, выполните:

```cmd
powershell -NoProfile -Command "[Environment]::SetEnvironmentVariable('Path', [Environment]::GetEnvironmentVariable('Path', 'User') + ';C:\msys64\ucrt64\bin', 'User')"
```

**Достаточно выполнить команду одним из двух способов.**

> **ВАЖНО!**
>
> Если MSYS2 установлен в другой папке, укажите свой путь к `ucrt64\bin`.

После выполнения команды **перезагрузите компьютер**.

## 8. Повторно проверяем G++

После перезагрузки откройте CMD и выполните:

```cmd
g++ --version
```

Теперь полный путь к компилятору указывать не требуется.

Если появилась информация о версии GCC, значит, всё настроено правильно.

> **ВАЖНО!**
>
> Если команда не работает, напишите мне или обратитесь за помощью к любой GPT.

## 9. Устанавливаем Visual Studio Code

Установите **Visual Studio Code (VS Code)**.

Во время установки:

1. Примите условия лицензионного соглашения.
2. На этапе дополнительных задач установите все необходимые галочки.
3. Завершите установку.
4. Перезагрузите компьютер.

## 10. Устанавливаем расширения для C++

Откройте Visual Studio Code.

1. Перейдите в раздел **«Расширения» (Extensions)**.
2. В строке поиска введите `C++`.
3. Найдите и установите расширение **C/C++ Extension Pack** от Microsoft.
4. Также найдите и установите **C/C++ Build Task** от `kaysonwu`.

## 11. Устанавливаем русский язык в VS Code

1. Откройте раздел **«Расширения» (Extensions)**.
2. В строке поиска введите `rus`.
3. Найдите **Russian Language Pack for Visual Studio Code** от Microsoft.
4. Установите расширение.

## 12. Меняем язык и открываем конфигурацию

Для открытия палитры команд нажмите:

**Ctrl + Shift + P**

Далее:

1. Введите `Configure Display Language`.
2. Выберите **Русский язык**, если он ещё не выбран.
3. При необходимости перезапустите VS Code.
4. Снова откройте палитру команд с помощью **Ctrl + Shift + P**.
5. Введите `C/C++: Edit Configurations (UI)` и выберите соответствующую команду.

> **ВАЖНО!**
>
> В палитре команд необязательно вводить название команды полностью. Если нужная команда уже появилась в списке подсказок, её можно сразу выбрать.

## 13. Настраиваем IntelliSense

В открывшейся конфигурации необходимо изменить несколько параметров.

### Имя конфигурации

Можно оставить без изменений.

### Путь к компилятору (Compiler Path)

Раскройте выпадающий список, нажав на стрелочку справа, и выберите установленный компилятор G++.

В моём случае путь следующий:

```text
C:/msys64/ucrt64/bin/g++.exe
```

У вас путь может отличаться, если MSYS2 был установлен в другую папку.

### Режим IntelliSense (IntelliSense Mode)

Выберите:

```text
windows-gcc-x64
```

### Стандарт C++ (C++ Standard)

Выберите:

```text
c++20
```

После изменения настроек конфигурация будет сохранена в файле `c_cpp_properties.json`.

## 14. Настраиваем папку .vscode

После настройки IntelliSense в рабочей папке проекта должна появиться папка:

```text
.vscode
```

Внутри неё находится файл:

```text
c_cpp_properties.json
```

Именно его мы настраивали через интерфейс конфигурации.

Теперь необходимо создать ещё один файл — `tasks.json`.

### Создаём tasks.json

1. В проводнике VS Code найдите папку `.vscode`.
2. Нажмите на неё **правой кнопкой мыши**.
3. Выберите **«Создать файл»**.
4. Назовите новый файл `tasks.json`.
5. Скопируйте приведённый ниже код и вставьте его в созданный файл.
6. Сохраните файл сочетанием **Ctrl + S**.

### Код для tasks.json

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Build C++20",
            "type": "shell",
            "command": "C:\\msys64\\ucrt64\\bin\\g++.exe",
            "args": [
                "-std=c++20",
                "-Wall",
                "-Wextra",
                "-Wpedantic",
                "${file}",
                "-o",
                "${fileDirname}\\${fileBasenameNoExtension}.exe"
            ],
            "options": {
                "cwd": "${fileDirname}"
            },
            "problemMatcher": [
                "$gcc"
            ],
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}
```

> **ВАЖНО!**
>
> Найдите в коде поле `command` и убедитесь, что в нём указан правильный путь к вашему компилятору G++.
>
> По умолчанию используется:
>
> `"command": "C:\\msys64\\ucrt64\\bin\\g++.exe"`
>
> Если MSYS2 установлен в другую папку, необходимо изменить этот путь. Обратите внимание, что в JSON используются двойные обратные слеши `\\`.

### Что делает эта конфигурация?

Она позволяет компилировать программы на C++ с помощью сочетания клавиш **Ctrl + Shift + B**.

При компиляции:

- Используется стандарт **C++20**.
- Включаются предупреждения компилятора (`-Wall`, `-Wextra`, `-Wpedantic`).
- Компилируется открытый в редакторе файл.
- Исполняемый файл `.exe` создаётся в той же папке, где находится исходный `.cpp`.
- Название исполняемого файла совпадает с названием исходного файла.

Например, при компиляции `main.cpp` будет создан файл `main.exe`.

## 15. Создаём и компилируем первую программу

Теперь всё готово для написания первой программы!

### Создание файла

В папке проекта создайте новый файл, например:

```text
main.cpp
```

Название может быть любым, главное, чтобы файл имел расширение `.cpp`.

> **ВАЖНО!**
>
> Файл с кодом программы необходимо создавать в папке проекта, **а не внутри `.vscode`**.

### Написание программы

Откройте созданный файл и напишите простой код:

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello World!";
    return 0;
}
```

### Сохранение программы

Нажмите:

**Ctrl + S**

### Компиляция программы

Убедитесь, что в редакторе открыт файл `main.cpp`, и нажмите:

**Ctrl + Shift + B**

Начнётся компиляция программы.

Если компиляция завершилась без ошибок, рядом с `main.cpp` появится файл `main.exe`.

## 16. Запускаем исполняемый файл

После успешной компиляции рядом с исходным файлом появится исполняемый файл с таким же названием, но с расширением `.exe`.

Например:

```text
main.cpp
main.exe
```

### Открываем терминал

В VS Code нажмите:

**Ctrl + Ё**

Откроется встроенный терминал.

Для запуска программы введите:

```powershell
.\main.exe
```

Если всё настроено правильно и терминал находится в нужной папке, появится:

```text
Hello World!
```

### Что делать, если исполняемый файл находится в другой папке?

Команда запуска зависит от расположения `.exe` относительно текущей папки терминала.

**Пример 1. Файлы находятся в корне проекта**

```text
project/
├── .vscode/
│   ├── c_cpp_properties.json
│   └── tasks.json
├── main.cpp
└── main.exe
```

Если терминал открыт в папке `project`, команда запуска:

```powershell
.\main.exe
```

**Пример 2. Файлы находятся во вложенной папке**

```text
project/
├── .vscode/
│   ├── c_cpp_properties.json
│   └── tasks.json
└── lesson1/
    ├── main.cpp
    └── main.exe
```

Если терминал открыт в папке `project`, команда запуска будет следующей:

```powershell
.\lesson1\main.exe
```

Таким образом, при запуске программы необходимо учитывать расположение исполняемого файла относительно текущей папки терминала.

### Как переходить между папками с помощью cd?

Для перемещения между папками в терминале используется команда `cd` (Change Directory — изменить текущую папку).

Предположим, мы находимся в папке `project`, а нужная программа лежит в папке `lesson1`.

**Переход в папку**

Чтобы перейти из `project` в `lesson1`, выполните:

```powershell
cd lesson1
```

Теперь терминал находится внутри папки `lesson1`, поэтому программу можно запустить короткой командой:

```powershell
.\main.exe
```

**Возвращение в предыдущую папку**

Чтобы вернуться на один уровень выше, выполните:

```powershell
cd ..
```

Теперь вы снова находитесь в папке `project`.

> **ВАЖНО!**
>
> Команда `cd ..` возвращает на один уровень вверх по структуре папок, а не обязательно в ту папку, где вы находились до этого.

### Пример работы с терминалом

Допустим, изначально терминал находится здесь:

```text
C:\Users\User\Desktop\project
```

Переходим в папку `lesson1`:

```powershell
cd lesson1
```

Теперь текущая папка:

```text
C:\Users\User\Desktop\project\lesson1
```

Запускаем программу:

```powershell
.\main.exe
```

Возвращаемся в папку проекта:

```powershell
cd ..
```

Теперь мы снова здесь:

```text
C:\Users\User\Desktop\project
```

**Полезно запомнить:**

- `cd lesson1` — перейти в папку `lesson1`.
- `cd ..` — вернуться на один уровень выше.
- `cd ..\..` — подняться сразу на два уровня выше.
- `.\main.exe` — запустить `main.exe` из текущей папки.
- `.\lesson1\main.exe` — запустить `main.exe` из вложенной папки `lesson1`.
